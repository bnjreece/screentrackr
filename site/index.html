Ask your movie library real questions.

screentrackr is a free, open-source command line tool and MCP server. It keeps what you own, what you've watched and how you rated it next to a full movie catalog built on your machine from IMDb's datasets, and lets you query both with the same filters.

For people who live in the terminal, and for anyone using Claude Code, Claude Desktop or another MCP client.

Install and build the catalog (Node.js 22.13 or newer):

$ npx screentrackr setup

Or just ask your agent

Add the MCP server to Claude Code with one command:

$ claude mcp add screentrackr -- npx -y screentrackr mcp

Then ask in plain words. The agent uses the same filters and query code as the CLI, so both give the same answers.

Claude Desktop works too: download the one-click extension, open it, then ask Claude to set up the movie catalog. No terminal or Node.js needed. Prefer config files? See the README.

  • Fincher or Villeneuve thrillers rated 7.5+ I haven't watched, under two hours.
  • Which Villeneuve movies do I own that I haven't watched?
  • What highly rated thrillers under two hours should I rent?
  • We watched The Glass Harbor tonight. Mark it watched and give it an 8.

Bring your library

Import what you already have. Each import matches your movies to IMDb ids so filters run on real fields, and you can review the ones it couldn't place.

Apple TV, copy and paste
Select your movie list in the TV app on a Mac, copy, and import the paste.
Apple TV app on macOS
Read the library directly with screentrackr import apple-tv (experimental).
CSV
Title, year, director, status, your rating, IMDb id, in any column order.
ScreenTrackr JSON
Export and re-import with nothing lost, for backups and moving machines.

Stays on your machine

Your library lives in a SQLite file in ~/.screentrackr/. There's no account, no server and no telemetry. The only network calls screentrackr makes are downloads of IMDb's dataset files from datasets.imdbws.com during setup.

Installing for good

$ npm install -g screentrackr
$ screentrackr setup

setup downloads about 1 GB and takes several minutes. Run screentrackr setup --refresh later for newer data.

About the data

No movie data ships with screentrackr. Each install downloads its own copy of IMDb's non-commercial datasets for that person's own personal use, under IMDb's terms. Don't redistribute the database it builds.
